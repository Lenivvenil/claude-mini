# feat(release): GitHub native auto-merge for trivial PRs

**Priority:** P2
**Estimate:** S
**Depends on (in this batch):** —

## Problem statement

Trivial PRs (dependabot patches, format-only commits) проходят через manual merge — налог на внимание без ROI.

## Acceptance criteria

- [ ] GitHub repo settings: auto-merge enabled.
- [ ] `.github/workflows/auto-merge-trivial.yml`: matcher на `dependabot/`, `chore: format`, `chore: lint-fix` labels.
- [ ] Все CI gates должны pass.
- [ ] Логируется в /gate-audit (тикет #5) как «auto-merge: 12 PRs/week».

## Non-goals

НЕ auto-merge feature PRs; НЕ skip review.
