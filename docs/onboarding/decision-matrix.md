# Decision matrix: какой вариант выбрать

Ответь на вопросы по порядку. Первый подходящий — твой вариант.

---

## 1. Это первое знакомство с claude-mini?

**Да** → [Minimal](minimal.md). Цель: убедиться что pipeline работает, потратить ≤30 минут.

**Нет** → вопрос 2.

---

## 2. Ты уже регулярно используешь Claude Code на этом проекте?

**Нет** → [Minimal](minimal.md). Сначала освойся с базовыми командами.

**Да** → вопрос 3.

---

## 3. Тебе важно чтобы коммиты всегда шли в правильном формате (`feat: что сделал #42`)?

**Нет / мне без разницы** → [Minimal](minimal.md). Governance hook не нужен.

**Да** → [Standard](standard.md) минимум.

---

## 4. Ты работаешь с несколькими инструментами (GitHub Issues, MCP-серверы)?

**Нет / только Claude Code** → [Standard](standard.md).

**Да** → [Standard](standard.md) и настрой нужные MCP из `.mcp.json`.

---

## 5. Проект идёт в продакшн или содержит важную логику?

**Нет / это pet project** → [Standard](standard.md) достаточно.

**Да** → [Full / Paranoid mode](full.md). CI, mutation testing, все агенты-критики.

## Если всё ещё не ясно

Начни с [Minimal](minimal.md). Это займёт 30 минут и даст ответ на практике: если pipeline работает комфортно — иди в Standard, если нет — разберись с блокером до расширения.
